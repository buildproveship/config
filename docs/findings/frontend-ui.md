Summary: Healthy core. Strict TypeScript, no lint or type suppressions, 880 + 871 tests pass, and v8 is the only design system after PR 104. The weak spots are tooling and process, not the components.
Top 3 risks: (1) nothing runs the checks automatically: no CI on push or PR, no linter, and the browser suites only run by hand (main has a known failing Site browser spec); (2) three regex "linters" written by hand (a fourth is in flight) instead of ESLint, stylelint or an HTML validator; (3) ReleaseReady still installs a vendored `ui-web 0.8.0` tarball that contains the deleted Mantine code, and main ships different code under the same version number.
