# universal-playwright-framework — findings (2026-11-18, commit 947301d77fe7aba4df0e819044e4ca793d4e6562)

Summary: The product code (adapters v1/v2/imported-v1, runtime login, input preparation, execution, validation, reporting) is strict TypeScript, uses zod, and has a large synthetic test suite. Around it sits a legacy generic "Gig Grid" scaffold (about 4,900 lines) that no consumer uses, and the tooling only covers a small part of the repo.
Top 3 risks: (1) legacy scaffold kept alive by a compatibility test that pins `any` types for consumers that do not exist; (2) ESLint and Prettier cover only `src` and `tests`, ESLint 8 is end-of-life, and `npm test` runs a template suite against `localhost:3000` instead of the real suites (two test files are never run at all); (3) no automatic CI, so "all checks pass" depends on running about 20 scripts by hand.
After fixes (main 21137cb): `npm test` runs ESLint 10 + Prettier over every TS file and every suite, and passes. Main was red before (UPF-20).
Tool results: `npm run build` OK; `tsc --noEmit -p tsconfig.json` 0 errors; `tsc -p examples/authoring` 0 errors; `npm run lint` (src+tests only) 0 problems, but ESLint over all TS = **6 errors** (scripts/adapter-contract.test.ts, data-references.test.ts, owned-local-adapter.test.ts); Prettier over all TS = **4 files unformatted**. Suppressions: 3 `eslint-disable` (2 `no-explicit-any` that exist only to keep legacy `any` types), 0 `@ts-ignore`/`@ts-expect-error`, 0 `.only`/`.skip`, 24 `as unknown as` casts in tests. `npm audit --omit=dev`: 0. `npm audit` (dev): **9 high**, all from `@typescript-eslint` 6 → globby → fast-glob. `npm outdated`: 13 (majors: eslint 8→10, typescript-eslint 6→8, eslint-plugin-playwright 0.18→2, @cucumber/cucumber 12→13, @cucumber/gherkin 38→43, cucumber-expressions 19→20, allure-playwright 2→3, dotenv 16→18, @types/node 20→26, typescript 5.8→7). **knip and jscpd not run**: the auto-mode classifier blocks `npx --yes` downloads (same as the frontend-ui session); unused exports were found by grepping the three consumer repos instead. Consumers checked: ReleaseReady (pins 9b6b036), releaseready-product-tests and test-data-management (both pin 2160a5aa).
