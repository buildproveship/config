# universal-api-framework — findings (2026-11-18, commit 34de0627d1399b038c134924478b9c6f25af294a)

Summary: Small repo (≈3,500 lines). The intake code (`src/intake`) and the smoke tests are strict TypeScript and already use the official libraries (native `fetch`, `yaml`, Ajv draft-04, Swagger Parser); there is no hand-written retry, HTTP client library or schema validator. The k6 performance harness (≈1,570 lines) is untyped JavaScript.
Top 3 risks: (1) no linter or formatter at all, and the JavaScript performance harness is never type-checked (178 strict errors when checked); (2) no single check command: `npm test` skips the 29 performance tests and nothing runs on a PR; (3) the Dev performance profile pins a ReleaseReady revision that is 426 commits behind main.
After fixes (main after PR 19): `npm run check` passes — typecheck 0 errors over 3 programs, ESLint 0 problems, Prettier clean, `npm test` 39/39, `test:performance` 35/35.
Tool results (before fixes): `npm run typecheck` 0 errors; `npm test` 39/39 pass; `npm run test:performance` 29/29 pass once k6 is installed (10 fail without it, with a clear message); strict `checkJs` over `performance/*.mjs` + `tests/*.mjs` = **178 errors** (mostly implicit `any`); ESLint/Prettier: **not configured**; suppressions: 0 `eslint-disable`, 0 `@ts-ignore`/`@ts-expect-error`, 0 `any`, 0 `.only`/`.skip`; `npm audit --omit=dev` 0; `npm audit` 0; `npm outdated` 3 (`@apidevtools/swagger-parser` 13.0.0→13.1.0, `@types/node` 22→26, `typescript` 5.9→7.0). **knip and jscpd not run**: the auto-mode classifier blocks `npx --yes` downloads (same as the other sessions); unused exports and duplication were checked with grep. Consumers checked: ReleaseReady only holds a revision-pinned test inventory snapshot (`scripts/repository-inventory/generated/releaseready--universal-api-framework.1.json`, revision af65bba); no repo imports this code.
